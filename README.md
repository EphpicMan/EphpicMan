# EphpicMan

**A developer-focused toolkit for testing, diagnosing, and troubleshooting WordPress applications.**

Ephpicman is an open-source WordPress project focused on helping developers identify problems, inspect their environments, and test WordPress applications more effectively.

The project is being built with an emphasis on:

* **Diagnostics** — identify common WordPress, PHP, server, and configuration issues.
* **Testing** — provide practical tools for testing WordPress applications and extensions.
* **Developer Experience** — make technical problems easier to understand and investigate.
* **Extensibility** — provide a solid foundation for custom diagnostics and developer tooling.
* **Automation** — support automated checks and workflows as the project evolves.

## Status

**Early development**

Ephpicman is currently under active development. The architecture and feature set may evolve as the project is tested against real-world WordPress development needs.

## Goals

The long-term goal is to provide a practical developer toolkit that brings WordPress diagnostics and testing capabilities together in one extensible project.

Planned areas include:

* Environment diagnostics
* WordPress health checks
* PHP and configuration checks
* REST API diagnostics
* HTTP and loopback testing
* Plugin and theme diagnostics
* Diagnostic reports
* Developer APIs and custom checks
* WP-CLI integration
* Automated testing
* CI/CD integration
* Advanced diagnostics

Features will be introduced gradually based on real development requirements rather than building a framework for its own sake.
